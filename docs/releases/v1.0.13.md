# v1.0.13 — Cinema-noir look, Continue watching, Sonarr series tags

_Released: 2026-10-29_

This is the first tagged release of WatchVault. Versions 1.0.5 to 1.0.12 were built and published
as images but never tagged, so this note covers everything since 1.0.4.

## Highlights

WatchVault has a new cinema-noir look across the whole app, a "Continue watching" block on the
dashboard fed by Plex progress and your Sonarr/Radarr calendars, and a list of your running
Sonarr series that you can tag to add them to WatchVault.

## ✨ Features

- **Cinema-noir restyle** (#111, #112, #113). New design tokens, shell and dashboard, a title page
  with a full-bleed backdrop, poster and display title, and the same look on search, overviews,
  settings, imports, genre pages and sign-in. (1.0.7, 1.0.8, 1.0.9)
- **"Continue watching" dashboard block** (#114). Shows Plex progress and the Sonarr/Radarr
  calendars. (1.0.10)
- **Choose how many days of downloads "Continue watching" shows** (#115). Sonarr/Radarr downloads
  from the last 0–30 days. (1.0.11)
- **List and tag running Sonarr series** (#116). Only series you tag are added to WatchVault; tags
  are the normal household tags (Settings → Tags), survive title merges, and removing a tag leaves
  the title in place. (1.0.12)
- **Infuse on Apple TV is recognised as a scrobble source** (#110). (1.0.6)

## 🐛 Bug fixes

- **Images were not published after a green run on `main`** (#109). The delivery workflow now
  publishes the validated image on every push to `main`. (1.0.5)

## 📄 Docs / Internal

- Release workflow and release notes per version (this release, 1.0.13): `.github/workflows/release.yml`,
  `docs/releases/`. No change to the app.
- Visual baselines regenerated for the new look (#111, #112).
